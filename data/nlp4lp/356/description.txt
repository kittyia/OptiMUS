Background: We want to describe a hybrid scheduling system. The system allows some students to attend in-person classes with social distancing while their peers attend online, the schedules vary by day. We consider the problem where students have unique, individualized class enrollments and one. The students who are scheduled to attend all classes in person on a given day may, at times, be required to attend a particular class on that day online because of social distancing constraints. These instances are counted as excess. We minimize the excess. Our objective is to maximize interaction
    
Objective: Minimize a weighted sum of total excess (TE), total deviation (TD) and surplus simultaneous excess (SSE), where the weight of the TE metric is normalized to be one, the weight of the TD metric, $\lambda$ is set so that $\lambda \ll 1$ and in practive, we set $\lambda=0.25$, the weight of the SSE metric $\mu$ is set to that $\mu \rr \lambda$, in practice we set this to zero

Parameters:
- \mathcal{S} (|\mathcal{S}|): Set of students
- \mathcal{C} (|\mathcal{C}|): Set of classes
- \mathcal{A} (|\mathcal{S}|, |\mathcal{C}|): Set of students enrolled in class $k$
- c_k (|\mathcal{C}|): Social distancing capacity in class $k$
- E (): Excess room capacity
- s_j^t (|\mathcal{G}|, |\mathcal{T}|): Surplus students at time $t$ for group $j$
- \mathcal{C}_t (|\mathcal{C}|): Set of classes scheduled to be ongoing at time $t$, where $t$ deontes an hour in a week. t=0 corresponds to midnight and T=T=167 corresponds to Saturday at 11:00 pm
- \matcal{T} (|\mathcal{T}|): Set of hours in a week
- \lambda (): The weight of the TD (total deviation) metric
- \mu (): The weight of the SSE (surplus simultaneous excess) metric
- G (): Number of groups
- \pi_{i,j} (|\mathcal{S}|, |\mathcal{G}|): \pi_{i,j} is an indicator variable for if student $i$ is assigned to group $j$

Constraints:
- Each student should be assigned to exactly one group
- For each day in the term we pick a group $j$ to be assigned to in-person attendance for all of the day's classes and cycle through all groups one by one for each day of the term
- If a class has more assignments than the social distancing capacity, we assign some students randomlly to an "excell room" for the duration of that class
- The excess room has capacity $E$
