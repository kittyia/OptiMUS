Background: We want to describe a hybrid scheduling system. The system allows some students to attend in-person classes with social distancing while their peers attend online, the schedules vary by day. We consider the problem where students have unique, individualized class enrollments and one. The students who are scheduled to attend all classes in person on a given day may, at times, be required to attend a particular class on that day online because of social distancing constraints. These instances are counted as excess. We minimize the excess. Our objective is to maximize interaction
    
Objective: Maximize the weighted sum of total Excess (TE), total deviation (TD) and surplus simultaneous excess (SSE), where the weight of the TE metric is normalized to be one, the weight of the TD metric, $\lambda$ is set so that $\lambda \ll 1$ and in practive, we set $\lambda=0.25$, the weight of the SSE metric $\mu$ is set to that $\mu \rr \lambda$, in practice we set this to zero

Parameters:
- \mathcal{S} (|\mathcal{S}|): Set of students
- \mathcal{C} (|\mathcal{C}|): Set of classes
- \mathcal{A}_k (|\mathcal{S}|, |\mathcal{C}|): Set of students enrolled in class $k$
- c_k (|\mathcal{C}|): Social distancing capacity in class $k$
- \mathcal{C}_t (|\mathcal{C}|): Set of classes scheduled to be ongoing at time $t$, where $t$ deontes an hour in a week. t=0 corresponds to midnight and T=T=167 corresponds to Saturday at 11:00 pm
- \matcal{T} (|\mathcal{T}|): Set of hours in a week
- \lambda (): The weight of the TD (total deviation) metric
- \mu (): The weight of the SSE (surplus simultaneous excess) metric

Constraints:
- Exactly four learning teams (LTs) attenting classes in person on each day
- Longitudinal balance being maintained. This means days of in-person atten-dance should be equally distributed throughout the term
- Balance over days of the week being maintained. Because classes follow a schedule that repeats weekly, each team should attend classes in person on each day of the week an equal number of times
