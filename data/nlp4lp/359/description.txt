Background: We want to optimize the waste collection system for a city, taking full account of the city's particular characteristics. We want to find a collection truck route for each zone and minimize its length.
    
Objective: Minimize the length of the route that visits each node in T exactly once

Parameters:
- A_P (|A_P|): The set of arcs representing one-way block sides
- E_P (|E_P|): The set of edges representing two-way block sides
- \ell_{(i,j)} (|A_P|, |A_P|): Each arc $(i,j)$ is weighted by the length of the block side it represents
- F (|F|): Set of traffic restictions, for example if travel from $(i,j)\rightarrow (j,k)$ is forbidden, $(i,j,k)\in F$
- \gamma_{(i,j)} (|A_P|, |A_P|): Shortest path between i, j that has no forbidden paths as subpaths
- s (): Starting point for the truck is represented by $s \in V$
- t (): Arrival point for the truck is represented by $t \in V$
-  (|V_T| + |A_T|): The complete digraph T=(V_T, A_T), where V_T=V_Z\cup\{s,t\} and the weight $w_{(i,j)} of arc $(i,j)$ is given by $\ell(\gamma_{(i,j)})$
- \mathcal{L} (|\mathcal{L}|): The set of block sides that cannot be serviced under the achique system. \mathcal{L}={e in A_S \cup E_S: \ell(e) > 130}
- F_4 (|F_4|): Forbidden path with four nodes
- L_e (): For each $e \in \mathcal{L}$, $(i,j) \in A_T$ belongs to $L_e$ if any of the arcs representing $e$ are part of $\gamma_{(i,j)}$
- V_{(i,j)} (|V_T|, |V_T|): For any $(i,j)\in V_T$, $i \neq j$, $V_{(i,j)}$ is the set of all $k \in V_T$ such that if $u$ is the second-to-last node in $\gamma_{(i,j)}$ and $v$ is the second node in $\gamma_{(j,k)}$, then $(u,j,v)\in F$
- B_\delta (|B_\delta|): For each $\delta=(u_1,u_2,u_3,u_4) \in F_4, v \in V_T$ belongs to $B_\delta$ if and only if the last arc in $\gamma_{v, u_2}$ is $(u_1,u_2)$
- \hat{B}_\delta (|\hat{B}_\delta|): For each $\delta=(u_1,u_2,u_3,u_4) \in F_4, v \in V_T$ belongs to $\hat{B}_\delta$ if and only if the two last arcs in $\gamma_{v, u_3}$ are $(u_1,u_2)$ and $(u_2,u_3)$
- E_\delta (|E_\delta|): For each $\delta=(u_1,u_2,u_3,u_4) \in F_4, v \in V_T$ belongs to $E_\delta$ if and only if the first arc in $\gamma_{u_3, v}$ is $(u_3,u_4)$
- \hat{E}_\delta (|\hat{E}_\delta|): For each $\delta=(u_1,u_2,u_3,u_4) \in F_4, v \in V_T$ belongs to $\hat{E}_\delta$ if and only if the two first arc in $\gamma_{u_2, v}$ are $(u_2,u_3)$ and $(u_3,u_4)$

Constraints:
- Each node in T is visited exactly once
- Avoid formation of subtours
- The trucks directly service all block sides that are too long to be handled under the achique system
- Impose that $t$ is the last node visited
- Avoid violating traffic restrictions when passing from the end of one shortest path to the start of the next
- Some paths of length three and four are forbidden and cannot be used
