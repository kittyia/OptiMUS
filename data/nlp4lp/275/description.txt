Consider a communication network made up of several nodes. These nodes are connected by communication links that allow one-way transmission of data from one node to another. Each link between nodes has a specific capacity, meaning it can carry a certain number of bits per second, and there is a cost associated with transmitting data along each link. 
Each node in the network generates data that needs to be sent to another specific node. This data can be sent directly or by passing through several intermediate nodes. Additionally, data from the same origin to the same destination can be split up and sent through different paths.
The goal is to determine the paths that all data should take to reach their intended destinations, while keeping the total transmission cost as low as possible.
