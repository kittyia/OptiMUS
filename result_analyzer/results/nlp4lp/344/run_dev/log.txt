### Reasoning

1. **Supply constraints**  
   \[

2. **Demand constraints**

3. **Route feasibility constraint**

   This constraint is **redundant if decision variables are defined only for routes (i,j) ∈ A**.  
   In standard LP modeling practice, we define decision variables only on feasible arcs. If that is done, this restriction is automatically enforced and does not need to be written as a separate constraint.

4. **Non-negativity constraints**  
   \[
   \text{amount}_{i,j} \ge 0
   \]  
   These are necessary and cannot be removed.
