\[
\min \sum_{k=1}^K |y_k - (c x_k^2 + b x_k + a)|

\[
d_k \ge |y_k - (c x_k^2 + b x_k + a)|
\]

\[
-d_k \le y_k - (c x_k^2 + b x_k + a) \le d_k
\]

Then the LP objective becomes:

\[
\min \sum_{k=1}^K d_k
\]

Without these constraints, the \( d_k \) variables would not correctly represent the absolute deviations, and the model would be incorrect.
